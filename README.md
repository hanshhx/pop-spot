# POP-SPOT

서울의 팝업스토어를 검색하고, 위치와 운영 기간을 확인할 수 있는 사이트입니다.

**[팝스팟 바로가기](https://popspot.co.kr)**

- 이름·지역·카테고리로 팝업을 검색할 수 있습니다.
- 지도에서 팝업 위치를 보고, 상세 페이지에서 운영 기간과 장소를 확인할 수 있습니다.
- 관심 있는 팝업을 찜하고 방문할 곳을 골라 코스를 만들 수 있습니다.
- 한국어·영어·일본어 화면을 지원하며, PC와 모바일 브라우저에서 사용할 수 있습니다.

버전별 수정 내용은 [릴리즈](https://github.com/hanshhx/pop-spot/releases)에 정리했습니다.
