# 번역 백필 — 시험 돌리고 검수하기

지도·카드에 쓰는 일본어·영어 이름을 채우는 절차. **한 번에 다 돌리지 않는다** — 틀린 이름은
빈칸보다 나쁘기 때문이다. 빈칸이면 한국어 원문이 나와서 최소한 틀리지는 않는다.

## 왜 이 문서가 있나

2026-08-06 에 운영 데이터를 훑었더니 일본어 이름 170건 중 눈에 띄는 오역이 많았다.

| 원문                          | 나온 값                        | 문제                           |
| ----------------------------- | ------------------------------ | ------------------------------ |
| 명탐정 코난 팝업스토어        | コナン・ハイウェイへの天国の扉 | 작품명이 문장이 됐다           |
| 남대문잡채호떡                | 南山拌菜熱米糕                 | 중국어 + **남대문을 남산으로** |
| 마티에 프리미에르 더현대 서울 | … ソウル **1F**                | 없는 층수를 지어냈다           |
| 라네즈                        | ラネーズ                       | 공식 표기는 ラネージュ         |

공통점은 하나였다 — **전부 용어집(`PopupTranslationGlossary`)에 없던 이름**이다. 용어집에
있는 것(짱구·귀멸·산리오)은 정확했다. 프롬프트를 아무리 잘 써도 소용이 없다. 모델은 자기가
틀렸다는 것을 모르기 때문이다. 그래서 **아는 이름은 잠그고, 모르는 이름은 비운다.**

남대문 → 南山이 가장 나쁘다. 어색한 정도가 아니라 관광객을 다른 동네로 보낸다.

## 순서

### 0. 배포 확인

용어집에 28개를 추가했다(2026-08-06). **jar 를 다시 올리지 않으면 아무 효과가 없다.**

### 1. 백필 전 상태 저장

```bash
node scripts/review-translations.mjs snapshot
```

### 2. 한 배치만 돌린다

```
POST /api/admin/popups/backfill-translations
```

한 번에 최대 100건이다(`popspot.crawler.translation-backfill-limit`). 더 적게 보고 싶으면
그 값을 낮춘 뒤 재시작한다.

**아직 `bulk` 을 쓰지 않는다.** 그건 배치를 계속 돌린다.

### 3. 결과를 눈으로 본다

```bash
node scripts/review-translations.mjs diff
```

새로 채워진 것만 나온다. 기계가 잡을 수 있는 것(한글 잔존·중국어 의심·일본 문자 없음·
원문에 없는 숫자)은 위쪽에 모아 준다.

> **표시가 없다고 맞는 것이 아니다.** `마이멜로디 하모니 → マイメロディ ヒーメナ` 같은
> 오역은 일본어처럼 생겨서 기계가 못 잡는다. 아래 목록도 반드시 눈으로 훑는다.

### 4. 판단

- 틀린 것이 거의 없다 → 5번으로.
- 틀린 것이 눈에 띈다 → **멈춘다.** 그 이름들을 용어집에 추가하고 2번부터 다시.

### 5. 전체 돌리기

```
POST /api/admin/popups/backfill-translations/bulk
GET  /api/admin/popups/backfill-translations/status
```

## 이미 틀리게 채워진 것을 다시 번역시키려면

**대량 백필은 비어 있는 행만 다시 집는다.** 틀리게 채워진 행은 영원히 그대로다.

다시 돌리려면 그 행을 비워야 한다. `<id들>` 자리에 검수에서 모은 id 를 넣는다.

```sql
UPDATE popup_store
   SET name_ja = NULL, name_en = NULL, location_ja = NULL,
       location_en = NULL, translated_at = NULL
 WHERE id IN (<id들>);
```

DB 접속은 `sudo -u postgres psql -d popspot_db`.

**`WHERE` 없이 실행하지 말 것.** 맞게 번역된 것까지 날아가고 다시 채우는 데 LLM 시간이 든다.

## 참고

- 야간 자동 백필이 돌고 있다. 즉 **용어집을 배포하기 전까지는 틀린 이름이 계속 쌓인다.**
- 번역이 없으면 화면은 한국어 원문으로 물러선다(`bilingual()`). 비어 있는 것 자체는 사고가
  아니다.
- 지도는 목록에서 번역명 아래에 한국어 원문을 작게 보여 준다 — 현장에서 간판과 대조하기
  위해서다.
