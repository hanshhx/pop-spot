## 네이버 오픈 API 약관 — 확인 결과

크롤 구조 자체는 깨끗하다. 스크래핑 라이브러리가 의존성에 0개이고, 신원을 밝힌
UA(`popspot-crawler/1.0 (+https://popspot.co.kr)`)로 공식 API 만 호출하며, 원문
대신 LLM 재서술본만 저장한다. 크롤링 판례들의 쟁점(상대 서버 직접 크롤·원문 복제)에
들어가지 않는다.

**남는 회색지대는 API 제공자와의 약관 하나다.**

- 7.3.③ 이 "취득한 정보를 무단으로 복제·저장(캐시 포함)·가공" 을 금지한다.
  popspot 은 검색 결과에서 사실을 뽑아 자체 DB 를 만든다.
- 검색 API 특약 2.1 은 "검색결과를 독립적으로 노출" 을 요구한다. 좁게 읽으면
  노출할 때의 규칙이라 적용 대상이 아니고, 넓게 읽으면 벗어난다.

위험의 성격은 **소송이 아니라 API 키 정지**(9.4·12.1)다.

### 다만 어차피 없어진다

부칙 제2조 — Search API 는 2026-07-30 로 신규 접수가 닫혔고, 기존 이용자도
**2027-06-30 까지**다. 이후 NAVER API HUB(NCP)로 이관해야 한다.

> 무료 API 의 "저장 금지" 조항은 대개 유료 상품을 팔기 위한 장치다. 이 문제는
> 법적으로 다투기보다 유료 전환으로 넘어가는 편이 보통 정답이다. 다만 NCP 는
> 호출당 과금이라, 이관 전에 호출량을 줄이는 설계를 해 두면 그때 돈이 덜 든다.

**할 일**: 이용 형태(사실 정보만 추출·출처 표시·무료·무광고)를 적어 네이버에
문의하고 회신을 보관한다. 사전 문의 기록 자체가 방어 자산이다.
