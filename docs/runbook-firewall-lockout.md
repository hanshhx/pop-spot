# 관리자 페이지에 못 들어갈 때 — 긴급 해제 절차

`/admin` 방화벽 규칙 때문에 본인이 잠겼을 때 읽는 문서다.
**당황해서 읽는 문서라 순서대로만 따라가면 되게 썼다.**

---

## 0. 먼저 확인 — 정말 방화벽인가

브라우저에서 `https://popspot.co.kr/admin` 을 열었을 때:

| 증상                          | 원인                 | 어디로                   |
| ----------------------------- | -------------------- | ------------------------ |
| **403** 또는 Vercel 차단 화면 | 방화벽               | 아래 1번                 |
| 캡차·체크박스가 뜸            | 방화벽 **Challenge** | 통과하면 됨. 안 되면 1번 |
| `/login` 으로 튕김            | 로그인 만료          | 그냥 다시 로그인         |
| 500 / 빈 화면                 | 방화벽 아님          | 백엔드 로그 확인         |

**로그인 화면이 뜬다면 방화벽 문제가 아니다.** 여기서 멈춰도 된다.

---

## 1. 규칙 끄기 — 1분

방화벽 규칙은 **저장·해제 모두 즉시 반영된다. 재배포가 필요 없다.**

1. https://vercel.com/dashboard 접속 (여기는 방화벽과 무관하게 열린다)
2. `popspot` 프로젝트 선택
3. 왼쪽 **Firewall**
4. 오른쪽 위 **⋯** → **Configure**
5. `/admin` 규칙을 찾아 **Disable**
6. 오른쪽 위 **Review Changes** → **Publish**

**여기까지가 전부다.** 몇 초 안에 풀린다.

---

## 2. 대시보드에 못 들어갈 때

1번이 안 되는 경우는 Vercel 계정 자체에 못 들어가는 것이다.

### 2FA 기기를 잃어버렸다면

**복구 코드**를 쓴다. 2FA 켤 때 저장하라고 했던 그 코드다.
로그인 화면에서 "다른 방법으로 인증" 을 골라 입력한다.

> 복구 코드를 어디에 뒀는지 지금 기억나지 않는다면, **이 문서를 덮고 먼저 찾아 두자.**
> 잠긴 다음에 찾으면 늦다.

### 복구 코드도 없다면

Vercel 지원에 문의하는 수밖에 없다 — https://vercel.com/help
**하루 이상 걸릴 수 있다.** 그래서 복구 코드 보관이 중요하다.

---

## 3. 그동안 서비스는?

**사용자 쪽은 멀쩡하다.** 방화벽 규칙은 `/admin` 에만 건다. 팝업 목록·지도·검색은
그대로 돌아간다. 급한 건 관리자 화면뿐이다.

백엔드는 Tailscale 로 계속 닿는다. 데이터를 급히 봐야 하면:

```bash
# 서버에 접속한 뒤
sudo -u postgres psql -d popspot_db
```

단, **`/admin` 화면 자체를 Tailscale 로 열 수는 없다.** 그 화면은 Vercel 에 있다.

---

## 4. 다시 켤 때 — 같은 사고를 반복하지 않으려면

### 규칙은 반드시 대시보드에서 만든다

`vercel.json` 에도 방화벽 규칙을 쓸 수 있지만 **거기 쓰면 안 된다.**
코드라서 **해제하려면 배포해야 하고**, 잠긴 상태에서는 배포 자체가 막힐 수 있다.
대시보드 규칙은 클릭 한 번이면 꺼진다.

### 순서를 지킨다

Vercel 공식 권고이자 우리 계획이기도 하다.

```
① Log 로 만들어 1~2일 관찰      ← 내 IP 가 실제로 뭔지 확인
② 그다음 Challenge 또는 Deny
```

**집·회사 인터넷은 IP 가 바뀐다.** 고정이 확실하지 않으면 `Deny` 대신
**`Challenge`** 를 쓴다. 사람은 통과하고 봇은 막힌다 — 잠길 일이 없다.

### 켜기 전 체크리스트

- [ ] Vercel 계정 2FA 켜져 있다
- [ ] 복구 코드를 안전한 곳에 저장했다 (비밀번호 관리자 등)
- [ ] 규칙을 대시보드에서 만들었다 (`vercel.json` 아님)
- [ ] Log 모드로 1~2일 관찰했다
- [ ] 내 IP 가 유동이면 Deny 가 아니라 Challenge 다

---

## 참고 — 이 규칙이 막지 못하는 것

방화벽은 **Vercel 을 지나는 요청**만 본다. 다음은 백엔드를 직접 부르므로
방화벽을 지나지 않는다.

```
아바타 업로드          /api/v1/users/me/avatar
채팅 이미지 업로드      /api/chat/upload
관리자 사진 백필·중복정리
실시간 로그 스트림      /api/admin/logs/stream
```

그래서 방화벽만으로는 관리자 보안이 끝나지 않는다. 백엔드 자체 방어(요청 제한·
TOTP·재인증)가 따로 필요하고, 그건 개편 계획 B단계에 있다.
